# JAZZNIM GLOW BEAUTY

A responsive, original **HTML5 + CSS3 only** online product showcase created for a school web-development activity.

## Files
- `index.html` — home page and featured fictional product concepts
- `about.html` — brand story and project disclaimer
- `gallery.html` — product gallery
- `css/style.css` — all styling and responsive layouts
- `images/image-files/` — reserved folder for image assets

## Important project requirements
- No JavaScript is used.
- No frameworks or JavaScript libraries are used.
- Navigation uses ordinary HTML links.
- Layout and visual effects use CSS only.
- The brand and all four products are fictional concepts created for this assignment.
- Sample prices are imaginary design placeholders, not actual selling prices.

## Preview locally
Open `index.html` in a browser. Keep the three HTML files and the `css` folder together.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `jazznim-glow-beauty`).
2. Upload the contents of this folder to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages publishes the site, open the provided URL and test all three navigation links.
